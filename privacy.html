Política de Privacidade

1. Informações coletadas

O NoirFlow pode receber informações básicas da conta do TikTok quando o usuário autoriza a integração, conforme as permissões concedidas durante o processo de login.

2. Uso das informações

As informações são utilizadas para permitir a autenticação do usuário e fornecer os recursos de integração e publicação de conteúdo solicitados pelo usuário.

3. Dados de autenticação

Os dados e tokens de autenticação são utilizados somente para fornecer as funcionalidades autorizadas pelo usuário.

4. Compartilhamento

O NoirFlow não vende informações pessoais. Informações podem ser processadas por serviços de terceiros quando isso for necessário para fornecer as funcionalidades solicitadas pelo usuário.

5. Segurança

Adotamos medidas razoáveis para proteger as informações processadas pelo serviço. Nenhum método de transmissão ou armazenamento eletrônico é completamente seguro.

6. Exclusão de dados

O usuário pode solicitar a exclusão dos dados associados ao uso do NoirFlow entrando em contato com o responsável pelo serviço.

7. Alterações

Esta Política de Privacidade poderá ser atualizada quando necessário.

8. Contato

Para dúvidas ou solicitações relacionadas à privacidade, entre em contato com o responsável pelo NoirFlow.
